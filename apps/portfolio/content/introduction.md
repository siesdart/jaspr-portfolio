**“좋은 설계는 개발자가 쉽고 생산적으로 개발할 수 있게 명확한 경계를 만드는 것에서 시작합니다.”**

안녕하세요. 사용자 경험(UX)과 개발자 경험(DX)을 동시에 고려하며, 웹 성능 최적화와 확장적 아키텍처 설계 등 세부 과정을 집요하게 고민하는 프론트엔드 엔지니어 박현우입니다.
베이글코드 웹 프론트엔드 인턴십 등 개발 경험을 바탕으로 공통 컴포넌트 라이브러리 제작, CDD 기반 아키텍처 구축, UX 최적화를 주도했습니다.

- **프론트엔드 엔지니어**: TypeScript, React, Next.js 생태계를 바탕으로 당장의 기능 구현에 그치지 않고 장기적인 관점에서 개발 생산성을 높일 수 있는 확장적 아키텍처를 추구합니다.
- **웹 성능 최적화 & 렌더링 UX**: User-Agent 기반 SSR 기기 분기로 모바일 접속 시 발생하던 레이아웃 시프트(CLS)를 해결하였으며, React 지연 로딩과 ForesightJS 마우스 예측 프리페치를 결합하여 모달 오픈 시 INP를 112ms에서 64ms로 최적화했습니다.
- **디자인 시스템 & 공통 컴포넌트**: 20여 종의 사내 공통 React UI 라이브러리를 설계·개발하고, Storybook 기반 정적 사이트 CI/CD 배포 파이프라인 구축을 주도하여 사내 개발 생산성과 UI 일관성을 확보했습니다.
- **CDD 기반 확장형 아키텍처**: Configuration Driven Development(CDD) 아키텍처를 적용해 파편화된 데이터 뷰 코드를 JSON 설정 체계로 공통화 및 정리함으로써, 유지보수에서 반복적으로 나타나는 비효율을 줄이고 개발 생산성을 대폭 향상시켰습니다.
- **에이전트 제어 & 하네스 구축**: 선언적 타입스크립트 패턴, UI 컴포넌트 트리 리뷰 등의 에이전트 스킬을 직접 작성하여, AI 생성 코드의 품질과 일관성을 제어하고 빠르게 교정할 수 있는 체계를 구축하였습니다.
- **웹 프레임워크 오픈소스 기여**: Dart 기반의 모던 웹 프레임워크인 Jaspr의 DOM 검증 버그, Hydration unescape 오류 등을 수정하여 PR 5건을 기여(Merged)하였습니다.
