- **프론트엔드 엔지니어**: TypeScript, React, Next.js 및 Dart/Flutter 생태계를 바탕으로 견고하고 확장성 있는 아키텍처를 추구합니다.
- **디자인 시스템 & 백오피스 플랫폼**: 베이글코드 웹 프론트엔드 엔지니어링 인턴으로서 20여 종의 사내 공통 React UI 라이브러리와 Storybook 배포 파이프라인을 구축하고, CDD(Configuration Driven Development)를 도입해 반복적인 개발 공수를 대폭 경감했습니다.
- **성능 최적화 및 렌더링 UX**: User-Agent 기반 SSR 기기 분기로 레이아웃 시프트(CLS)를 방지하고, SSG 사전 생성 및 예측형 프리페칭을 사용해 초기 로딩 지연을 최적화한 경험이 있습니다.
- **AI 도구 및 오픈소스 기여**: MCP(Model Context Protocol) 기반 사내 패키지 LLM 통합 웹 허브와 에이전트 하네스를 구축했으며, Jaspr 모던 웹 프레임워크의 코어 렌더링/빌드 파이프라인 버그를 패치(PR 5건 머지)하는 등 오픈소스 생태계에 직접 기여해보았습니다.

**“좋은 설계는 개발자가 시스템을 오용하기 어렵게 명확한 경계를 만드는 것에서 시작합니다.”**

초등학생 시절 컴퓨터를 만지다 자연스럽게 기존에 존재하는 프로그램만이 아닌 나만의 프로그램을 직접 만들고 싶다는 욕구가 생기게 되었고, 인터넷에서 VB.NET이라는 이름의 프로그래밍 언어를 알게된 것을 시작으로 컴퓨터를 통해 실용적인 가치를 만들 수 있는 프로그래밍이란 분야에 빠져들기 시작하였습니다. 개발에 재미를 붙여 10년이 넘는 시간 동안 취미로 삼아 다양한 언어와 기술을 접하고 여러 서비스를 만들어보며, 새로운 환경에서도 빠르게 기술 스택을 이해하고 학습해 개발을 진행할 수 있는 역량을 갖추었습니다. 현재는 React를 주력으로 함과 동시에 Dart/Flutter 생태계를 애용하여 깊이 파고드는 등, 프론트엔드를 중심으로 서비스 개발을 위한 다양한 기술에 관심을 가지며 학습을 이어가고 있습니다.

오랫동안 프로그래밍을 접하고 경험해오면서 다음과 같은 개발 철학을 지니게 되었습니다:

1. 런타임에서의 안정성이 보장되는 견고함과, 생산성 있는 개발 속도가 보장되는 간결함이 균형을 이루는 구조를 추구합니다.
2. 정적 타입을 통한 컴파일 타임 에러 예방이 가능한 언어를 선호하며, Strict 한 린터 등의 개발 환경 설정을 통해 휴먼 에러를 시스템적으로 극복하고자 노력합니다.
3. 역할과 책임이 명확히 드러나는 객체지향과 인터페이스의 의도를 한눈에 파악하기 좋은 선언형 프로그래밍을 결합하여, 개발자가 코드를 파악하는 인지 부하를 줄이고자 합니다.
4. 전반적인 프로젝트 구조나 경계를 연결하는 인터페이스만으로 개발자에게 코드 변경이나 사용의 충분한 가이던스가 될 수 있는, 이해하기 쉽고 명확한 코드 설계를 지향합니다.
5. 대중적인 기술에 안주하기보다 상황에 가장 알맞은 최적의 대안 기술을 리서치하고 발굴하는 과정을 즐깁니다.
6. 어떤 아키텍처나 패러다임도 절대적인 정답은 없음을 인지하며, 상황에 가장 적합한 실용적이고 유연한 코드 설계를 지향합니다.
7. 구현이라는 결과만이 아닌, 이를 위해 어떤 방식으로 코드를 작성하는 것이 가장 좋을지, 어떤 방식으로 구현해야 사용자에게 더 나은 가치를 줄 수 있을지 등 DX/UX 양면의 세부적인 과정에 포커스를 맞추고 집요하게 고민합니다.

코드는 혼자 작성하는 작업물이 아닌 동료와 함께 만들어가는 결과물이기에, 기술적 최적화를 넘어 읽기 쉽고 의도가 투명하게 드러나는 구조를 가진 코드가 아름다운 코드라는 믿음으로 항상 고민하며 개발을 하고 있습니다. 동료와 LLM을 가리지 않고 활발한 코드 리뷰와 기술 토론을 통해 팀 전체의 코드 품질을 높이는 것을 중요하게 생각합니다. 내가 작성하는 코드가 누군가가 사용하는 서비스가 된다는 것을 실감하며 사용자 중심의 인터페이스를 구현하고 개선해나가는 데에 큰 보람을 느낍니다.
