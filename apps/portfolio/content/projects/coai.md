## 1. 프로젝트 개요

- **배경 및 목적**: KAIST 몰입캠프 4주차 프로젝트로, 개발자 간의 코드 질의응답뿐만 아니라 생성형 AI(GPT)가 답변을 작성해주는 Q&A 플랫폼을 구축하고자 기획되었습니다.
- **핵심 목표**: 사용자가 질문을 등록할 때 LLM이 생성하는 답변을 지연 없이 실시간 스트리밍으로 클라이언트에 전달하고, 생성된 답변을 누락 없이 데이터베이스에 저장하는 백엔드 파이프라인 구축.

## 2. 담당 역할 및 핵심 기능

- **담당 역할**: 백엔드 REST API 설계 및 Swagger를 통한 프론트엔드와의 협업 체계 구축, PostgreSQL 스키마 및 Drizzle ORM 모델링, LangChain 연동 및 스트리밍 파이프라인 전담 (팀원은 프론드엔드 전담)
- **핵심 기능 목록**:
  - **게시글 및 질의응답 CRUD API**: 개발자 질문, 답변, 댓글 등을 관리하는 API 엔드포인트
  - **타입 안전한 데이터 관리**: Drizzle ORM 기반의 스키마 마이그레이션 및 타입 세이프 쿼리 빌딩
  - **GPT 연동 실시간 스트리밍 AI 답변**: 새 질문 작성 시 LangChain을 통해 GPT 모델과 연동되어 실시간으로 스트리밍되는 답변 제공
  
## 3. LLM 활용 방향 및 범위

- 프로젝트 수행 당시는 아직 LLM 초창기라 활용에 신중했기에 사용하지 않았습니다.

## 4. 핵심 기술적 의사결정 및 문제 해결

### 1) Node.js Transform Stream 기반 이중 스트림 처리 파이프라인 설계

- **상황 및 과제**: LangChain을 통해 OpenAI로부터 들어오는 실시간 텍스트 청크를 기존 응답 DTO 내용과 함께 클라이언트에 즉각 전송해야 함과 동시에, 생성이 완료된 전체 답변 본문을 데이터베이스에 저장하여 클라이언트에서 새로고침 후에도 휘발되지 않도록 해야했습니다. 전체 LLM 텍스트를 모두 수신하고 나서야 응답 DTO를 작성하고 클라이언트로 전송하는 방식은 UX 상 부적절하다 판단했습니다.
- **기술적 의사결정**: 리서치 후 청크 전송 인코딩을 사용하여 응답을 보내며, Node.js의 `Transform` 스트림을 활용하여 단일 스트림 내에서 기존 응답 내용 및 청크의 클라이언트 전송과 청크 텍스트 병합을 동시에 처리하는 파이프라인을 구상했습니다.
- **구현 및 해결**: `Transform` 클래스의 인스턴스를 생성하여 먼저 생성자에서 일반 응답 DTO를 stringify하여 스트림으로 푸시하고, LangChain 응답 스트림으로부터 유입되는 청크를 `transform` 메소드에서 다시 푸시하면서 선언해둔 문자열 변수에 이를 병합한 후 스트림이 종료되는 시점에 완성된 문자열을 데이터베이스에 저장하도록 구현했습니다.
- **결과 및 영향**: 프론트엔드에서 즉각적인 스트리밍 렌더링 UI를 구현할 수 있게 되었으며, 서버 측에서는 데이터 유실 없이 데이터베이스에 답변이 적재되는 파이프라인을 완성했습니다.

## 5. 주요 성과

- 1주일이라는 짧은 기간 내에 백엔드 전체 아키텍처 및 LLM 스트리밍 연동 파이프라인을 안정적으로 구현 완료
- 캠프 최종 데모 시연에서 실시간 AI 답변 생성을 포함한 서비스 전체 기능 오류 없이 성공적 시연
